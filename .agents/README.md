# Plan & Decision Artifacts

This directory holds planning artifacts (ADRs, design specs, plans,
research notes) produced by the AI workflow. See
`.claude/templates/artifacts/` for templates and
`.claude/rules/meta-ai-config.md` for conventions.

`adr/adr_artifact_mirroring.md`, `specs/design_artifact_mirroring.md` and
`plans/plan_artifact_mirroring.md` are the founding records of this tool.
They were written in the grimoire repository and moved here with it; they
describe `grim-mirror` as it was designed, before the repository split.
